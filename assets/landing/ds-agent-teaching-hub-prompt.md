# Image-gen-2 Prompt: DS Agent Teaching Hub Landing Image

Create a 16:9 editorial hero image for a GitHub teaching repository.

## Style

- Polished technical education poster.
- Clean evidence-board composition.
- Light neutral background, black ink, steel blue and green accents.
- No official product logos.
- No fake screenshots.
- Readable labels, sparse text.
- Should feel like a practical curriculum for data scientists, not a marketing banner.

## Title Text

DS Agent Teaching Hub

1. Skills
   Visual: reusable playbook folder, SKILL.md page, small checklist.

2. Subagents
   Visual: main thread delegating to three compact analyst panels.
   Label: Parallel review and delegation.

3. Codex
   Visual: app thread, artifact page, receipt, handoff prompt.
   Label: Workflow to receipt.

Add a thin path line connecting:

Prompt -> Workflow -> Artifact -> Receipt -> Handoff
