## What The X Posts Are Doing Structurally

### Pattern A: Contrarian diagnosis

Formula:

```text
Most people think the problem is X.
Actually the problem is Y.
Here is the workflow that fixes Y.
```

Examples from bookmarks:

- PPT quality problem is not model ability; it is missing aesthetic constraints.
- Token cost problem is not that the model reads too much; it is uncapped command output.
- Skill problem is not writing one skill; it is version drift and governance.

Workshop translation:

```text
Most people think Codex onboarding means learning every feature.
Actually the problem is knowing where work should live and how to leave evidence.
```

### Pattern B: Concrete workflow before abstraction

Formula:

```text
Here is the exact thing I did.
Here are the steps.
Here is what changed.
Now here is the general rule.
```

Workshop translation:

Do not start with "threads, plugins, MCP, skills." Start with:

```text
We will migrate one existing RovoDev workflow into Codex App.
At the end, you will have a worksheet, a receipt, and a next-session prompt.
```

Then explain threads/artifacts/skills as they appear.

### Pattern C: Visuals are positioned as proof

Formula:

```text
Claim -> screenshot/artifact -> what to inspect -> reusable lesson
```

The image is not decorative. It is the thing that makes the claim credible.

Workshop translation:

Every visual should answer one of these:

- What did Codex create?
- What changed from the old workflow?
- What should I inspect before trusting it?
- What can I reuse next week?

### Pattern D: One reusable phrase

X posts usually leave you with a phrase you can repeat:

- "Show, don't tell."
- "Skills stop drifting."
- "Token hygiene."
- "Receipts create trust."
- "Peer review, not delegation."

Current package has good ideas but too many phrases.

Recommended workshop slogan:

> Start with a workflow. End with a receipt.

Secondary slogan:

> Rovo for Atlassian-native context. Cursor for editor-native code. Codex App for visible workflow artifacts. Codex CLI for terminal harness.
