# Image-gen-2 Prompt: Receipt Anatomy Evidence Board

Create a 16:9 evidence-style image for a technical X post.

## Style

- Looks like an annotated real work receipt, not a generic diagram.
- Editorial evidence board, off-white paper texture, black monospace snippets, steel blue section labels, amber risk markers.
- Use markdown document fragments, file list chips, checkmarks, warning tags, and a next prompt block.
- No official logos, no fake branded product screenshots.
- Keep text concise and readable.

## Title

Anatomy Of A Trustworthy AI Receipt

## Main Object

A large markdown receipt page centered on the canvas, with callout lines pointing to each section.

## Receipt Sections

1. Goal - "What the agent was asked to accomplish"
2. Inputs Inspected - "Files, tickets, docs, or threads actually read"
3. Tools Used - "Shell, MCP, plugins, browser, image generation"
4. Artifact Created - "Worksheet, checklist, viewer, report, or handoff"
5. Verification - "Tests, checks, source review, visual inspection"
6. Risks - "Unknowns, policy caveats, unsupported connectors"
7. Next Prompt - "The exact prompt a teammate can use to continue"

Important callout:
"Atlassian context is not RovoDev-only: Codex App/CLI can use Atlassian MCP when configured."

Footer:
A receipt is the difference between a nice answer and inspectable work.
