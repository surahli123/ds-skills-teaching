# Image-gen-2 Prompt: Before/After Workflow Evidence Board

Create a 16:9 evidence-style image for a technical X post.

## Style

- Looks like a sharp workflow evidence board, not an abstract infographic.
- High-contrast editorial layout, off-white canvas, black ink, steel blue accents, small amber highlights.
- Screenshot-like panels, terminal snippets, markdown receipt fragments, arrows, sticky annotations.
- No official logos, no fake branded UI screenshots, no decorative gradients.
- Text must be sparse, large, and readable.

## Title

Before: One-Off AI Chat
After: Workflow With Evidence

## Composition

Split the image into two halves.

Left half, labeled "Before":
- A terminal/chat panel with a single prompt.
- A loose Jira/Confluence note fragment.
- A fading answer bubble.
- Red annotation: "No artifact".
- Red annotation: "No verification".
- Red annotation: "Hard to hand off".

Right half, labeled "After":
- A Codex App thread panel.
- A visible worksheet artifact panel.
- A markdown receipt panel.
- A handoff prompt panel.
- Include a small route label: "Atlassian context can enter through RovoDev CLI or Codex via Atlassian MCP when configured".
- Blue annotation: "Inspectable artifact".
- Blue annotation: "Receipt".
- Blue annotation: "Next-session prompt".

Footer:
Start with a workflow. End with a receipt.
